🎓 Students Performance Analysis
📌 Project Overview

This project analyzes students' academic performance using the dataset "Students Performance in Exams" available on Kaggle.

The objective is to identify key factors that influence student success, such as demographic characteristics, parental level of education, and test preparation.

🎯 Objectives
Analyze student distribution by gender
Evaluate pass/fail rates in Mathematics and Reading
Study the impact of parental level of education
Create a custom grade classification system (A–F)
Analyze correlations between scores (Math, Reading, Writing)
Compare the performance of prepared vs non-prepared students

🛠 Tools & Technologies
Python
Pandas
Matplotlib
Seaborn
Power BI

📂 Dataset
Dataset source:
👉 https://www.kaggle.com/datasets/spscientist/students-performance-in-exams

📊 Grade Classification System
Score Range	Grade
Above 80	A
70 – 80	B
60 – 70	C
50 – 60	D
40 – 50	E
Below 40	F (Fail)

📈 Key Insights
Students who completed the test preparation course achieved better results
Strong positive correlation between Math, Reading, and Writing scores
Parental level of education influences student performance
Most students fall within the B and C grade categories
